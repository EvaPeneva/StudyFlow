# ✦ StudyFlow — Ученически планер

**Училищен проект №01 | 10. клас | Екип от двама | 5 седмици**

**Участници:** Ева Пенева и Михаела Сотирова — 10.Б клас  
**GitHub:** https://github.com/EvaPeneva/StudyFlow  
**Текуща фаза:** Етап 1 — проучване, планиране и първи резултати.

## За проекта

StudyFlow е двуезично уеб приложение (BG/EN) за ученици от 7. до 12. клас, с което ще могат да планират задачи, срокове и изпити по предмети, да следят календар и да получават напомняния. Ще се използват HTML, CSS, JavaScript, Supabase и GitHub.

## Какво има в началния прототип

- 3 начални изгледа: **Табло**, **Моите задачи** и начален преглед **Календар (списък по дати)**.
- Навигация между изгледите.
- Добавяне на задача с предмет, срок и приоритет.
- Отбелязване на задача като готова и изтриване.
- Търсене и филтриране по статус.
- Статистика за брой задачи.
- Смяна на езика **BG/EN**, без да се губят въведените задачи.
- Временен запис в **localStorage** (само на устройството/браузъра).

**Още НЕ са готови:** Supabase, Auth, RLS, редактиране на задачи, пълен месечен календар, истински напомняния и собствен алгоритъм за приоритизиране. Те са планирани за Етапи 2–4. `database/schema.sql` е **проектна чернова и не означава, че базата вече е създадена**.

## Стартиране

Приложението използва `type="module"`, затова не го отваряйте само чрез двойно кликване върху `index.html`.

**Вариант A — Visual Studio Code:** инсталирайте разширението **Live Server**, натиснете с десен бутон върху `index.html` → **Open with Live Server**.

**Вариант B — Python (ако е инсталиран):** отворете терминал в главната папка и изпълнете:

```bash
python -m http.server 8000
```

После отворете http://localhost:8000/.

## GitHub — задание на екипа

1. Създайте **public** repository с име `StudyFlow` (без лични данни или секрети).
2. Поканете съотборника: **Settings → Collaborators → Add people**.
3. Качете структурата, документите и кода.
4. Създайте **12 GitHub Issues**, вижте `docs/GITHUB_ISSUES.md`.
5. Създайте **GitHub Project**, примерно `StudyFlow • 5 weeks` с `Todo`, `In progress`, `Done`.
6. **Всеки** участник да направи **поне един истински собствен commit от собствения си GitHub акаунт**. Примерен разделителен подход: ученик 1 редактира дизайн/HTML/CSS, ученик 2 редактира ER/документацията за данните; двамата проверяват кода.
7. В `docs/WEEK_1_REPORT.md` впишете реалните линкове към repository, Project, Issues и commit-и и реалните дейности.

### Примерни git команди (изпълняват се от реалните участници)

```bash
git clone https://github.com/USERNAME/StudyFlow.git
cd StudyFlow
# Добавете файловете, които действително сте създали или редактирали.
git add .
git commit -m "Add initial StudyFlow project structure"
git push
```

**Важно:** URL с `USERNAME` е пример — не е създадено хранилище автоматично. Вторият ученик трябва да влезе със своя акаунт и да направи собствен commit, след като редактира свой файл.

## Публикуване (когато сте готови)

Settings → Pages → Deploy from a branch → `main` / root. Адресът ще зависи от истинския GitHub профил и repository. В Етап 1 публикуването не е задължително.

## Етика и безопасност

Използвайте истински, но не лични учебни демо записи. Не качвайте пароли, Supabase service-role ключове, имейли на ученици или лични данни. И двамата трябва да могат да обяснят кода и документите.
