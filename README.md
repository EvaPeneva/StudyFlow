## Инструкции за тестване - Етап 2

1. Изтеглете GitHub хранилището StudyFlow.
2. Отворете папката на проекта във Visual Studio Code.
3. Стартирайте `index.html` чрез разширението Live Server.
4. Използвайте бутоните в менюто за навигация между Табло, Моите задачи и Календар.
5. Превключвайте между BG и EN, за да проверите двуезичния интерфейс.
6. За тестване с реални данни е необходим тестов потребител в Supabase Auth и конфигурирана връзка в `src/supabase-config.js`. Данни за вход се предоставят отделно по сигурен начин.
7. След вход отворете Моите задачи и натиснете „+ Нова задача“.
8. Въведете заглавие, учебен предмет, срок и приоритет, след което запазете задачата.
9. Проверете дали задачата се появява в списъка и в таблицата `tasks` в Supabase.
10. Превключете езика от BG на EN и проверете дали задачите се запазват.

**База данни:** SQL схемата се намира в `database/schema.sql`.

**ER диаграма:** `design/ER_diagram.png`.

**Отчет:** `docs/WEEK_2_REPORT.md`.

**Забележка:** Проектът е прототип за Етап 2. Част от допълнителните функционалности предстои да бъдат разработени.
