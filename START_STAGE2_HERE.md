**Ева Пенева + Михаела Сотирова, 10.Б**

## Какво е готово във файла

- Подготвен обновен интерфейс (HTML/CSS/JS), две основни страници и трети календарен изглед;
- BG/EN, локално демо, форми за предмети/задачи, търсене, филтър;
- Подготвена връзка със Supabase с Auth и защитено четене/запис;
- SQL за 5 таблици и RLS, ER диаграма;
- Документация и шаблон `WEEK_2_REPORT.md`.

## Какво ЗАДЪЛЖИТЕЛНО правите вие

1. Използвайте актуалния GitHub проект — не създавайте втори.
2. Качете подготвените файлове от двата лични ZIP архива по реда в `docs/STAGE2_GITHUB_STEPS.md`.
3. Създайте в своя Supabase акаунт таблиците чрез SQL Editor и конфигурирайте URL + publishable key.
4. Влезте с тестов акаунт, заредете реалните примерни данни и проверете read + insert + update + RLS.
5. Направете истински скрийншоти от приложението и Supabase.
6. Попълнете действителните тестове, линкове към commits и индивидуални отчети в `docs/WEEK_2_REPORT.md`.

**Ако не изпълните стъпка 3–4, Supabase частта НЕ е завършена**, независимо че SQL файлът е подготвен.
