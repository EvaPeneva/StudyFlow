## 1. Какво планирахме?

През първия етап планирахме създаването на StudyFlow — двуезично уеб приложение, предназначено за ученици от 7. до 12. клас.

Основните ни задачи бяха:
- Проучване на три сходни приложения.
- Подготовка на проектен план и описание на алгоритъм.
- Изработване на два начални екрана.
- Планиране на база данни и ER диаграма.
- Създаване на общо GitHub хранилище.
- Разпределяне на минимум 12 GitHub Issues между двамата участници.
- Подготовка на седмичен отчет.

## 2. Какво реално изпълнихме?

С помощта на ChatGPT подготвихме начален пакет от файлове за StudyFlow.

Качихме в GitHub следните материали:

- `index.html` — основна структура на сайта.
- `style.css` — оформление и дизайн.
- `script.js` — начална JavaScript функционалност.
- `src/locales/bg.js` и `en.js` — преводи на български и английски.
- `docs/RESEARCH.md` — проучване на MyStudyLife, Todoist и Google Calendar.
- `docs/PROJECT_PLAN.md` — план на проекта.
- `docs/PRODUCT_SPEC.md` — описание на продукта.
- `design/01_dashboard.png` и `02_tasks.png` — два начални екрана.
- `design/ER_diagram.png` — схема на базата данни.

Създадохме общо GitHub хранилище, направихме commits от двата GitHub профила и създадохме 12 Issues — по 6 за всеки участник.

Създадохме и GitHub Project с колони Todo, In Progress и Done.

Началният прототип беше стартиран чрез Live Server. Проверихме добавянето на примерна задача и превключването между BG и EN.

## 3. Какво не е завършено?

Тези функционалности са планирани за следващите етапи.

Подготвените с ИИ документи все още се нуждаят от подробен самостоятелен преглед и проверка от двамата участници.

## 4. Какви затруднения срещнахме?

При работата с GitHub срещнахме затруднения при качването на папки и файлове.

Решихме проблема, като добавихме част от JavaScript файловете през GitHub редактора и качихме дизайните отделно.

Първоначално срещнахме затруднение и при стартирането на сайта чрез Live Server във Visual Studio Code.
